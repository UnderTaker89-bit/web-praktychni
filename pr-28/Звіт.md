# Практична 28 Робота з Docker

Підготовлено Dockerfile на основі nginx:stable-alpine, сайт у папці html, compose.yaml з портом 8080:80 та перевіркою HTTP. Початковий сайт з методички збережено окремо; html/index.html — власна друга версія.

Для виконання у терміналі VS Code запускайте послідовно:

1. `powershell -File .\Практична.ps1 Basics` — hello-world, BusyBox, образи, життєвий цикл контейнера.
2. `powershell -File .\Практична.ps1 Build` — збірка та запуск nginx.
3. Відкрийте http://localhost:8080.
4. Змініть html/index.html; `powershell -File .\Практична.ps1 Rebuild` видаляє контейнер цього проєкту, перебудовує образ і створює новий контейнер.
5. `powershell -File .\Практична.ps1 Check` зберігає фактичні списки образів, контейнерів і результат HTTP у Результати.
6. Зробіть скриншоти результатів docker image ls, docker compose ps та сторінки в браузері.
7. `powershell -File .\Практична.ps1 Stop` зупиняє цей проєкт.

Додатково команда Dev підключає html як том лише для читання: зміни стають доступними без перебудови. Цей режим не використовується для демонстрації оновлення образу.

## Фактичний стан

Docker Desktop і сучасний WSL на початку роботи не виявлено. Контейнерні команди ще не виконано; списки образів і контейнерів та їхні скриншоти не вигадані. Сайт можна перевірити окремо від контейнера, але така перевірка не підтверджує запуск nginx у Docker. Для завершення потрібне встановлення та перший запуск Docker Desktop.

Офіційний інсталятор завантажено на диск D, цифровий підпис Docker Inc підтверджено. Файли встановлення й наступні кроки наведено в папці Встановлення. Перезавантаження та прийняття ліцензійної угоди не виконувалися.

Сайт фактично відкрито через тимчасовий Python HTTP-сервер для перевірки верстки. Скриншоти/Попередній перегляд без Docker.png показує лише цей перегляд, а не роботу контейнера. Тимчасовий сервер зупинено, щоб звільнити порт 8080 для Docker.
