# Встановлення Docker Desktop

Офіційний інсталятор завантажено у `D:\прктичні\Програмування Веб\Встановлення Docker\Docker Desktop Installer.exe`. Його цифровий підпис перевірено: Valid, Docker Inc. Інсталятор не завантажується в GitHub.

На ПК Windows 10 build 19045; сучасну версію WSL не виявлено. На момент перевірки на диску C вільно близько 5 ГБ, тому сценарій задає розташування програми D:\DockerDesktop та даних D:\DockerData. Частина системних компонентів усе одно використовує диск C.

1. Відкрийте PowerShell від імені адміністратора та виконайте `wsl --install --no-distribution`. Якщо Windows попросить перезавантаження, збережіть роботу й перезавантажте ПК.
2. Виконайте `wsl --update`, потім `wsl --version`. Для WSL backend потрібна сучасна версія WSL і ввімкнена апаратна віртуалізація.
3. Запустіть підготовлений `Встановити.ps1` із цієї папки. Він запускає офіційний інсталятор із каталогами на диску D, без автоматичного прийняття ліцензійної угоди.
4. Відкрийте Docker Desktop, прочитайте й самостійно прийміть ліцензійну угоду, якщо погоджуєтеся. Оберіть Linux containers та дочекайтеся готовності рушія.
5. Перевірте `docker version` і `docker compose version`. Поверніться до сценарію Практична.ps1.

Факт завантаження інсталятора не означає, що Docker установлено. Установлення, перезавантаження, прийняття угоди та запуск рушія ще не виконувалися.

Офіційна інструкція: https://docs.docker.com/desktop/setup/install/windows-install/
