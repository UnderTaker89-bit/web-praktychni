# Результати перевірки практичної 26

Сервер .NET 10 зібрано без помилок. NuGet повідомив NU1900: мережевий доступ до індексу перевірки вразливостей був недоступний; пакети для збірки були в локальному кеші.

Виконано 13 реальних HTTP-перевірок із записом статусів, заголовків і тіл відповідей у HTTP-перевірка.json: GET списку, POST 201, GET за id, PUT 204, повторне читання змін, DELETE 204, GET видаленого запису 404, некоректний POST 400, CORS preflight OPTIONS 204, створення трьох демонстраційних записів і читання списку.

Окремо виконано фактичні функції з api.js у Node.js: createPosting, loadPosting, updatePosting, deletePosting; підтверджено обробку порожніх відповідей 204 та виняток HTTP 404.

У браузері перевірено всі три сторінки: початкову таблицю з п’ятьма полями, таблицю з десятьма полями, підсумкову з дев’ятьма полями й іншим порядком. Останні дві використовують той самий table.js. Значення `<img src=x onerror=alert(1)>` показується як текст, без виконання розмітки.

Після фактичного зупинення PostService кнопка оновлення показала «Не вдалося завантажити відправлення. Failed to fetch»; таблиця очистилася, кнопка стала знову доступною. Сервер після перевірки повторно запущено.
