# Практична 26

Відкрийте цю папку у VS Code. Потрібні .NET 10 SDK та Node.js 20 або новіший.

У першому терміналі: `dotnet run --project server/PostService --no-launch-profile --urls http://localhost:5000`.
У другому: `node serve.mjs`. Відкрийте http://localhost:3000.

`explicit.html` демонструє п’ять явно створених клітинок. `full.html` містить десять колонок. `index.html` змінює порядок і прибирає висоту; обидві останні сторінки використовують незмінений `table.js`.

У DevTools → Network оберіть запит postings: GET, 200, Content-Type application/json та JSON у Response. В Console виводиться масив відправлень. Запити CRUD наведено у http-requests.rest, їхні фактичні результати — у HTTP-перевірка.json.

Сервер скопійовано з попередніх практичних і доповнено CORS для localhost:3000 та 127.0.0.1:3000. Його DTO використовує рядки Standard/Express; ціна обчислюється на сервері. PUT/DELETE повертають 204, тому клієнт не викликає json() для порожньої відповіді.

У початковому рендері п’ять полів прописано безпосередньо. У підсумковому назви та порядок полів читаються з x-column; додавання колонки більше не потребує нових операцій DOM у JavaScript. textContent захищає від виконання HTML із даних.
